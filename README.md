# Proyecto Teorema 🧮

Teorema es una plataforma interactiva de aprendizaje matemático que conecta interfaces web modernas con motores de cálculo en Python.

## Módulos Actuales
* **Módulo 0:** Matemática básica, ejercicios de agilidad mental y operaciones algebraicas.
* **Módulo 1:** Álgebra intermedia, ecuaciones cuadráticas, factorizaciones avanzadas e inecuaciones.
* **Calculadora Factorizadora:** Herramienta interactiva de factorización con teclado matemático.

## Requisitos
Para correr los servidores locales necesitas Python instalado y las siguientes librerías:
- Flask
- SymPy
- python-dotenv

## Instalación
1. Clona este repositorio.
2. Crea un archivo `.env` en la raíz (puedes usar el código fuente como guía para la variable que falta).
3. Corre el backend del módulo que desees usar (ej. `python modulo_0/Back0.py`).
